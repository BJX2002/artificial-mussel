# 蓝湾监测任务

面向小学四至五年级的人工青口海洋监测教育游戏 Demo。游戏支持繁体中文、简体中文和英文界面，并可独立选择普通话、粤语或英语浏览器语音。

## 本地运行

在项目目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后打开 `http://127.0.0.1:4173/`。

游戏为纯静态网页，不需要安装依赖。进度保存在当前浏览器的本地存储中。

## 当前玩法

- S00–S15 完整垂直切片
- 两回合人工青口监测
- 四个固定地点与可复现的随机事件
- 第一回合简单确认放置
- 第二回合底部弹出任务卡，每个地点最多两个相关选项
- 证据盘、分级提示、调查报告、评分重试与现实科学结尾
