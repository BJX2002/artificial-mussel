# 人工青口出动！蓝湾监测任务（V6.1 Demo）

面向小学四至五年级的 10 分钟海洋科学游戏。学生亲手造一只人工青口，把它放进海里，回收并分析三份样本，再根据证据决定科学家的下一步调查。

## 本地运行

在项目目录执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

然后打开 `http://127.0.0.1:4173/`。入口页可选择电脑版或 iPad 版；两版共用同一套游戏内容和进度逻辑。游戏为纯静态网页，不需要安装依赖；刷新会回到标题页，只保留语言和语音偏好。

## 试玩入口

- `index.html`：给评审使用的版本选择页。
- `desktop.html`：电脑版，适合笔电、桌机和会议室大屏幕。
- `ipad.html`：iPad 版，针对横屏触控、较短的顶部栏和较大的点按区优化；竖屏仍可滚动使用。

V6.1 修复了组装页第 4 个结构热点无法继续的问题，并调整了铅、汞、镉资料卡的重点句与小字大小。

## V6 游戏流程

1. **接任务**：河口曾出现异常金属信号，但一次水样不足以下结论。
2. **找线索**：用观察镜发现清澈海水中仍可能有肉眼看不见的物质，再翻阅铅、汞、镉和放射性物质四份资料卡。
3. **亲手组装**：依次安装收集材料、凝胶与人工海水、带孔保护盖，再点完四个发光热点认识真实结构。
4. **测试原理**：开启水流，看见海水进入、材料留下线索、装置长期累积，而且不用电、不会清除污染。
5. **地图部署**：研究船沿路线从码头出发，把三只人工青口放到河口、保护区和第三个比较地点。
6. **等待八星期**：转动时间轮；遇到暴雨时从三个合理方案中选择能保留公平比较的方法。
7. **实验室分析**：亲手完成一份“开盖—取芯—入仪器”，其余两份由仪器按相同步骤处理，避免机械重复。
8. **比较证据**：把三张调查档案纸拖回地图并用图钉固定，找出较高地点，再区分“知道什么／还不知道什么”。
9. **作出决定**：在三个都能收集资料的计划中，选择既保留比较点、又增加上游线索和事件记录的方案。

完成后会出现真实人工青口照片和四条学习总结，也可以打开科学图鉴查看真实结构与研究边界。

## 设计原则

- 玩法由场景和操作推进，不以连续弹窗或答题卡作为主体。
- 半带领、半独立：前两只装置建立方法，第三只装置让学生参与选择。
- 答错不会卡关；系统解释误区后仍可继续。
- 重金属是主线，并说明含量过高可能影响海洋生物健康。
- 有害物质知识拆成四页资料卡，并分别说明铅、汞、镉和放射性物质；学生读完四页才进入制作阶段。
- 高、中、低只是本次任务中的相对信号，不是真实安全标准，也不能单独证明污染来源。
- 语音按内容播放；当前短句会同步高亮，完成页加入玩家自己的结尾报告。
- 支持繁体中文、简体中文、英文界面，以及普通话、粤语和英语浏览器语音。
- 电脑版会自动放大正文、任务栏、按钮、结果卡和反馈文字。
- iPad 版与电脑版共用任务逻辑，但使用独立的触控布局样式，方便以后同步维护。
